# أصوات الذكاء الاصطناعي العربية

تعمل بدون إنترنت بعد أول تنزيل، عبر محرك sherpa-onnx ونموذج piper العربي.

| الاسم | الصوت | عيّنة |
|---|---|---|
| `man` | رجل — **كريم** (الصوت المعتمد للراوي) | [استمع](samples/man.mp3) |
| `deep` | راوٍ عميق للتريلرات والوثائقي الثقيل | [استمع](samples/deep.mp3) |
| `woman` | امرأة | [استمع](samples/woman.mp3) |
| `child` | طفل | [استمع](samples/child.mp3) |
| `elder` | شيخ كبير | [استمع](samples/elder.mp3) |

**تنبيه صادق:** لا يتوفر حاليًا نموذج عربي مفتوح المصدر بصوت امرأة أو طفل أصلي، لذلك صوتا المرأة والطفل
مشتقّان من صوت كريم بتغيير طبقة الصوت والرنين. الطبقة صحيحة (امرأة ≈ 185 هرتز، طفل ≈ 245 هرتز) والنتيجة مقبولة،
لكنها أقل طبيعية من صوت الرجل. لصوت امرأة أو طفل طبيعي تمامًا: تسجيل بشري حقيقي، أو خدمة مدفوعة
(مثل ElevenLabs) ثم وضع الملف في الفلم.

- النص يجب أن يكون **مشكولًا بالكامل** لنطق صحيح.
- الاستخدام في الفلم: `say: {text: "...", voice: woman, at: 1.0}`
- من سطر الأوامر: `python3 studio.py voices "نَصٌّ مَشْكُولٌ"`
