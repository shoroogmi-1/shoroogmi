# خط إنتاج أي فيلم: أوامر إلزامية بمستوى فيلم سليماني

## فيلم النموذج
**النموذج هو `films/soleimani_mckee/`.** لا ينزل أي فيلم قادم عن مستواه.

| الملف | ما فيه |
|---|---|
| `model.mp4` | الفيلم النهائي: مرجع بصري وصوتي |
| `scene.py` | الكود الكامل |
| `story.yaml` | الخطة المملوءة: مثال لكل حقل |
| `n*.wav` | التعليق بصوت كريم بأسلوب المذيع |

## الأوامر بالترتيب

```bash
python3 studio.py new  <slug>                          # 1) ينسخ النموذج (scene.py) وقالب الخطة
#   اكتب السيناريو داخليًا في story.yaml (mode: idea) أو انسخ سيناريوها الجاهز (mode: script)
python3 studio.py plan films/<slug>/story.yaml         # 2) لا يُبدأ الرسم قبل «0 خطأ»
#   3) بحث: مصادر الوقائع + صور/أبعاد حقيقية (قاعدة محاكاة الواقع) → sources / visual_refs
#   4) عدّل اللقطات في films/<slug>/scene.py مع الإبقاء على أسلوب النص والصوت والحركة
python3 films/<slug>/scene.py x 2 6 12 18              # 5) لوحة فحص — انظر إليها وأصلح
python3 films/<slug>/scene.py                          # 6) إخراج كامل
python3 studio.py qa .cache/<slug>/<slug>.mp4 films/<slug>/story.yaml   # 7) فحص الجودة قبل التسليم
```

## ما يفحصه `plan` (من الكتابين وقواعدها)

| القاعدة | المصدر |
|---|---|
| الفكرة الحاكمة جملة واحدة = قيمة + سبب | مكّي |
| القيمة المركزية تنقلب في النهاية ولا ترجع | مكّي |
| شخصية محورية واحدة تظهر مبكرًا، ومعها أداة ارتباط عاطفي | Writing for Animation، ف10 |
| الهدف مادي ومحدد وقابل للشطب، وله مهلة | Writing for Animation، ف2 |
| الحادثة المحرّضة تقع على الشاشة وفي الربع الأول، والمشهد الملزِم يتحقق بعدها | مكّي، ف8 |
| كل لقطة تقلب قيمة، وفيها فجوة بين المتوقع والواقع، وفيها فعل مرئي | مكّي، ف2 وف7، وورشة الحوار |
| التعليق لا يتجاوز 2.4 كلمة في الثانية | الإيجاز وأسلوب المذيع |
| تأرجح الفكرة ونقيضها (+/−) مرتين على الأقل | مكّي، ف6 |
| تصاعد العقبات، والذروة أقوى لحظة ولا رجعة فيها | الكتابان |
| كل حلّ في النهاية مزروع مسبقًا | Writing for Animation، ف8 |
| مصادر للوقائع، ومراجع بصرية حقيقية | قاعدة محاكاة الواقع |
| 60 إطارًا في الثانية، وصوت anchor | مستوى سليماني |

## ما يفحصه `qa`

| البند | المطلوب |
|---|---|
| الدقة | 1080 على الأقل في الضلع الأقصر |
| معدل الإطارات | 60 إطارًا في الثانية |
| صيغة البكسل | yuv420p |
| الصوت | موجود |
| علوّ الصوت | ≈ −14 LUFS |
| المدة | تطابق الخطة |

## ثوابت مستوى سليماني التي يرثها كل فيلم من `scene.py`

- **المقاييس:** حقيقية بحساب بكسل لكل متر من طول الإنسان، والمركبات من `engine/vehicles.py`.
- **المشي البشري:** تدحرج القدم، ودوران الجذع المعاكس، والتداخل، والركبتان تنثنيان للأمام دائمًا.
- **الكاميرا:** تتبع الحركة، مع تأثير العمق (Parallax).
- **الإضاءة:** ظل ساقط، ومنظور جوي وخطي.
- **الصوت:** تعليق المذيع بملف `anchor`، وأصوات مصاحبة هادئة ومتزامنة، وخفض الموسيقى تحت الصوت، وعلوّ −14 LUFS.
- **أسلوب النص المعتمد:**
  - الترجمة السفلية بخط Cairo Bold بحجم 62.
  - بطاقات بيضاء ومائلة تظهر بقفزة.
  - عنوان الختام بخط Reem Kufi بحجم 120، وتحته بطاقة حمراء.
- **في أفلام الوقائع:** لا تحريف للوقائع. المعنى يأتي من اختيار الوقائع وترتيبها. وكل تفصيل غير موثق يُذكر لها في تنبيهات التسليم.
