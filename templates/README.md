# إدارة الموقع

## ⭐ الطريقة الأسهل: لوحة التحكم (Pages CMS)
1. افتحي **https://app.pagescms.org** واضغطي **Sign in with GitHub** (أول مرة فقط: اسمحي له بالوصول إلى مستودع الموقع).
2. اختاري مستودع الموقع.
3. من القائمة: **المقالات** أو **الكتب (أمتعة السفر)** أو **Media** (الصور والفيديو والملفات).
4. مقال جديد: **المقالات ← Add an entry** ← املئي العنوان والتاريخ واختاري التصنيف، واكتبي الاقتباس، والصقي نص المقال في المحرّر.
   - صورة داخل المقال: زر الصورة في شريط المحرّر ← ارفعيها أو اختاريها.
   - فيديو أو ملف PDF: ارفعيه من **Media** أولًا، ثم في المحرّر ظلّلي كلمة واضغطي زر الرابط واختاري الملف — يظهر الفيديو مشغّلًا والملف زر تحميل.
   - فيديو يوتيوب: الصقي رابطه وحده في سطر.
5. اضغطي **Save** — ينشر الموقع المقال وحده خلال دقائق بصوت حامد.
6. لتعديل مقال أو حذفه: افتحيه من القائمة ← عدّلي ← Save (أو ⋯ ← Delete).

**باقي تبويبات الموقع** من القائمة نفسها في اللوحة:
- **مُشعشعة (الصفحة الرئيسية):** بيت الشعر، والترحيب، و«أي خدمة؟».
- **جواز سفر:** العنوان والمحطات (أضيفي محطة أو عدّليها أو رتّبيها).
- **سجل الرحلات (التصنيفات):** أضيفي تصنيفًا أو احذفيه — يظهر في أزرار الفرز وفي قائمة تصنيف المقال بعد دقائق.
- **برج المراقبة:** العنوان، ومواضيع الرسالة، وحسابات التواصل.
- **سياسة الخصوصية وشروط الاستخدام.**
في النصوص: `**كلمة**` تظهر غامقة، و`[نص](رابط)` رابط.

اسم الملف يقترحه التاريخ والوقت (مثل 2026-10-18-2130)، ويمكنك كتابة اسم إنجليزي بدله عند الإنشاء — وهو رابط المقال.

# الطريقة اليدوية من GitHub (ما زالت تعمل)

كل ما تحتاجينه: تنسخين القالب، تملئين الفراغات، وتحفظين الملف في مكانه.
بعد الحفظ يعمل الموقع وحده خلال دقائق: يبني صفحة المقال، ويسجّله بصوت حامد، ويضيفه للبحث وللصفحة الرئيسية ولخريطة الموقع (قوقل).

---

## ✍️ إضافة مقال

1. افتحي المستودع على GitHub، ثم مجلد **`content/articles`**.
2. اضغطي **Add file ← Create new file**.
3. اسم الملف: كلمات إنجليزية صغيرة بينها شرطات، وينتهي بـ `.md` — مثل: `sana-barqih.md`
   (هذا الاسم يصبح رابط المقال: shoroogmi.com/blog/articles/sana-barqih.html)
4. انسخي محتوى الملف **`templates/article-template.md`** والصقيه، ثم املئي الفراغات.
5. اضغطي **Commit changes** (ثم Commit مرة ثانية).

### الحقول
الملف يبدأ بترويسة بين سطرين `---` (انسخيها من القالب):

| الحقل | ماذا أكتب؟ |
|---|---|
| title | عنوان المقال |
| date | بالأرقام الإنجليزية هكذا: `2026-10-12` |
| category | تصنيف أو أكثر، كل واحد في سطر يبدأ بـ `  - ` من القائمة تحت |
| quote | جملة مشوّقة من المقال: تظهر في بطاقة المقال وفي الصفحة الرئيسية |
| time | اختياري: `"21:30"` |
| kind | اختياري: `قصيدة` إن كان قصيدة |

### التصنيفات المسموحة (انسخيها كما هي حرفيًا)
- تأملات في القرآن والسنة
- شعب العلاقة مع القرآن
- مقالات نفسية واجتماعية
- مقالات فكرية
- مقالات تربوية
- مقالات إعلامية
- تقارير الإعلام الإيراني
- الذكاء الاصطناعي
- الشهرة والمشاهير
- القيادة
- الزاوية ٣٦
- قصائد

### داخل النص
- بين كل فقرة وفقرة **سطر فارغ**.
- سطر يبدأ بـ `## ` = عنوان فرعي.
- سطر يبدأ بـ `> ` = اقتباس داخل إطار.

### 📎 إرفاق صور وفيديوهات وملفات
**الخطوة ١ — ارفعي الملف:** افتحي مجلد **`assets/media`** ← **Add file ← Upload files** ← اسحبي الملف ← **Commit changes**.
سمّي الملف بحروف إنجليزية بلا مسافات، مثل `iran-chart.png` أو `lecture.mp4` أو `report.pdf`.
(الحد الأقصى لحجم الملف من المتصفح ٢٥ ميغابايت؛ الفيديو الطويل ارفعيه على يوتيوب وضعي رابطه.)

**الخطوة ٢ — اكتبي سطرًا في المقال في المكان الذي تريدينه، وحده بين سطرين فارغين:**

| أريد | أكتب في المقال |
|---|---|
| صورة | `![وصف يظهر تحت الصورة](iran-chart.png)` |
| عدة صور (معرض) | عدة أسطر صور متتالية بلا سطر فارغ بينها |
| فيديو مرفوع | `![وصف الفيديو](lecture.mp4)` |
| فيديو من يوتيوب | الصقي رابط يوتيوب وحده في سطر: `https://youtu.be/xxxxxxxxxxx` |
| مقطع صوتي | `![وصف المقطع](clip.mp3)` |
| ملف للتحميل (PDF أو Word…) | `[اسم الملف كما يظهر للقارئ](report.pdf)` — بلا علامة ! في أوله |

- الصورة والفيديو والصوت تبدأ بـ `!`، أما الملف للتحميل فبدونها.
- الصور القديمة في `assets/images` تبقى تعمل كما هي.
- القارئ الصوتي (صوت حامد) لا يقرأ هذه الأسطر.
- لحذف مرفق: احذفي سطره من المقال (ويمكنك حذف الملف من `assets/media` بالضغط عليه ← ⋯ ← Delete file).

## 📚 إضافة كتاب

1. ارفعي صورتي الغلاف (الأمامي والخلفي) إلى مجلد **`assets/books`**.
   سمّيهما مثلًا: `kitabi-front.jpg` و `kitabi-back.jpg`
2. في مجلد **`content/books`** أنشئي ملفًا جديدًا مثل `kitabi.md`.
3. انسخي **`templates/book-template.md`** والصقيه واملئي الفراغات (واكتبي اسمَي صورتي الغلاف كما رفعتِهما).
4. `order`: ١ يظهر أولًا، ٢ بعده… وهكذا.
5. `pdf` (اختياري): إن أردتِ أن يحمّل القارئ الكتاب، ارفعي الملف إلى `assets/books` وأضيفي سطرًا `pdf: kitabi.pdf`. واحذفي سطر `store` إن لم يكن للكتاب متجر.
6. Commit changes.

## 🌐 الترجمة الإنجليزية
المقال العربي يُنشر فورًا بصوته. أما النسخة الإنجليزية فتُضاف بملف بالاسم نفسه في `content/en/articles/`
(أو اطلبي من Claude: «ترجم المقال الجديد»). حتى تُضاف، يظهر المقال في الموقع العربي فقط.

## ⚠️ إن لم يظهر المقال
غالبًا خطأ صغير في الحقول (تصنيف غير موجود، أو تاريخ بغير الصيغة، أو اسم صورة خطأ).
افتحي تبويب **Actions** في GitHub: التشغيل الأحمر ❌ فيه سطر يشرح الخطأ بالعربية.
