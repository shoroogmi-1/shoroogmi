# قوالب إضافة مقال أو كتاب

كل ما تحتاجينه: تنسخين القالب، تملئين الفراغات، وتحفظين الملف في مكانه.
بعد الحفظ يعمل الموقع وحده خلال دقائق: يبني صفحة المقال، ويسجّله بصوت حامد، ويضيفه للبحث وللصفحة الرئيسية ولخريطة الموقع (قوقل).

---

## ✍️ إضافة مقال

1. افتحي المستودع على GitHub، ثم مجلد **`content/articles`**.
2. اضغطي **Add file ← Create new file**.
3. اسم الملف: كلمات إنجليزية صغيرة بينها شرطات، وينتهي بـ `.md` — مثل: `sana-barqih.md`
   (هذا الاسم يصبح رابط المقال: shoroogmi.com/blog/articles/sana-barqih.html)
4. انسخي محتوى الملف **`templates/article-template.md`** والصقيه، ثم املئي الفراغات.
5. اضغطي **Commit changes** (ثم Commit مرة ثانية).

### الحقول
| الحقل | ماذا أكتب؟ |
|---|---|
| العنوان | عنوان المقال |
| التاريخ | بالأرقام الإنجليزية هكذا: `2026-10-12` |
| التصنيف | واحد من القائمة تحت (أو أكثر بينها فاصلة «،») |
| الملخص | انسخي الفقرة الأولى نفسها |
| اقتباس | جملة مشوّقة من المقال للصفحة الرئيسية (اختياري — احذفي السطر إن لم تريديه) |
| الوقت | اختياري: `21:30` |
| النوع | اختياري: `قصيدة` إن كان قصيدة |

### التصنيفات المسموحة (انسخيها كما هي حرفيًا)
- تأملات في القرآن والسنة
- شعب العلاقة مع القرآن
- مقالات نفسية واجتماعية
- مقالات فكرية
- مقالات تربوية
- مقالات إعلامية
- الذكاء الاصطناعي
- الشهرة والمشاهير
- القيادة
- قصائد
- الزاوية ٣٦ ← المقال يظهر في صفحة الزاوية ٣٦

### داخل النص
- بين كل فقرة وفقرة **سطر فارغ**.
- سطر يبدأ بـ `## ` = عنوان فرعي.
- سطر يبدأ بـ `> ` = اقتباس داخل إطار.
- صورة: ارفعي الصورة أولًا إلى مجلد **`assets/images`** (Add file ← Upload files)، ثم اكتبي في المقال:
  `![وصف يظهر تحت الصورة](اسم-الصورة.jpg)`
  وعدة صور في أسطر متتالية = معرض صور.

---

## 📚 إضافة كتاب

1. ارفعي صورتي الغلاف (الأمامي والخلفي) إلى مجلد **`assets/books`**.
   سمّيهما مثلًا: `kitabi-front.jpg` و `kitabi-back.jpg`
2. في مجلد **`content/books`** أنشئي ملفًا جديدًا مثل `kitabi.md`.
3. انسخي **`templates/book-template.md`** والصقيه واملئي الفراغات (واكتبي اسمَي صورتي الغلاف كما رفعتِهما).
4. «الترتيب»: ١ يظهر أولًا، ٢ بعده… وهكذا.
5. Commit changes.

---

## 🌐 الترجمة الإنجليزية
المقال العربي يُنشر فورًا بصوته. أما النسخة الإنجليزية فتُضاف بملف بالاسم نفسه في `content/en/articles/`
(أو اطلبي من Claude: «ترجم المقال الجديد»). حتى تُضاف، يظهر المقال في الموقع العربي فقط.

## ⚠️ إن لم يظهر المقال
غالبًا خطأ صغير في الحقول (تصنيف غير موجود، أو تاريخ بغير الصيغة، أو اسم صورة خطأ).
افتحي تبويب **Actions** في GitHub: التشغيل الأحمر ❌ فيه سطر يشرح الخطأ بالعربية.
