# شروق المحمادي — الموقع الشخصي

موقع ثابت (HTML وCSS وJavaScript فقط) يعمل على GitHub Pages أو أي استضافة ملفات.

## الصفحات

| الصفحة | الملف |
|---|---|
| صالة المغادرة (الرئيسية) | `index.html` |
| جواز السفر (السيرة) | `sira.html` |
| سجل الرحلات (المدونة) | `blog/index.html` |
| رحلات طويلة (المقالات) | `blog/articles.html` و `blog/articles/*.html` |
| الزاوية ٣٦ | `blog/zawiya-36.html` |
| أمتعة السفر (الكتب) | `books.html` |
| برج المراقبة (التواصل) | `contact.html` |

التصميم في `assets/styles.css` والتفاعل في `assets/script.js`.

## تحديث الموقع

ملفات HTML تتولّد تلقائياً من `build.py`، فلا تعدّليها يدوياً (أي تعديل يدوي يُستبدل عند التوليد التالي).
بعد أي تغيير في المحتوى شغّلي:

```
python3 build.py
```

يحتاج فقط إلى Python 3، بدون أي مكتبات إضافية.

### إضافة مقال جديد

أنشئي ملفاً جديداً داخل `content/articles/`، واسم الملف يصبح رابط المقال
(مثلاً `my-new-post.md` يصبح `blog/articles/my-new-post.html`). استخدمي حروفاً إنجليزية وشرطات فقط في اسم الملف.

```
العنوان: عنوان المقال
التاريخ: 2026-10-15
التصنيف: تأملات
الملخص: جملة أو جملتان تظهران في بطاقة المقال.

الفقرة الأولى من المقال.

## عنوان فرعي

> اقتباس بارز يظهر داخل إطار أصفر.

فقرة أخرى.
```

- **الترويسة** (الأسطر الأربعة الأولى) مطلوبة كلها، ثم سطر فارغ، ثم النص.
- **التاريخ** بصيغة سنة-شهر-يوم، والمقالات تُرتَّب تلقائياً من الأحدث للأقدم.
- **التصنيف**: أي تصنيف جديد يظهر تلقائياً كزر فرز في صفحة رحلات طويلة.
- **مدة القراءة** تُحسب تلقائياً من طول النص.
- افصلي بين الفقرات بسطر فارغ.

بعد التوليد يظهر المقال في صالة المغادرة وسجل الرحلات وصفحة رحلات طويلة، وتتحدّث روابط «الرحلة السابقة/التالية».
لحذف مقال احذفي ملفه من `content/articles/` ثم شغّلي `python3 build.py`.

### الزاوية ٣٦ وأمتعة السفر وجواز السفر

هذه المحتويات قوائم داخل `build.py` نفسه:

- الخواطر: قائمة `ZAWIYA` (عنوان، تاريخ، نص)، والأحدث أولاً.
- الكتب: قائمة `BOOKS` (عنوان، مؤلف، الحالة، ملاحظة، لون الغلاف من `b1` إلى `b6`).
- محطات خريطة جواز السفر: قائمة `STATIONS` (أيقونة، عنوان، نص، شارة، ونوع خاص اختياري: `start` أو `fail` أو `award` أو `final`)، بالترتيب الذي تظهر به.
