# الخطوط السينمائية

كلها مجانية بترخيص SIL Open Font License (يُسمح باستخدامها تجاريًا). معاينة: [`previews/fonts.jpg`](../../previews/fonts.jpg)

## عربي

| المفتاح | الخط | متى يُستخدم |
|---|---|---|
| `amiri` | أميري (نسخ) | العناوين التاريخية والوثائقية الفخمة، والنصوص الدينية |
| `ruqaa` | عارف رقعة | الطابع التراثي والدرامي |
| `kufi` | ريم كوفي | العناوين الملحمية القوية (تريلر) |
| `qahiri` | قاهري | كوفي زخرفي للافتتاحيات وعناوين الفصول |
| `cairo` | القاهرة | الترجمة السفلية والنصوص التوضيحية (واضح على الجوال) |

## إنجليزي

| المفتاح | الخط | متى يُستخدم |
|---|---|---|
| `cinzel` / `cinzel_deco` | Cinzel | عناوين الأفلام الملحمية والتاريخية (طابع روماني) |
| `bebas` | Bebas Neue | التريلرات والأكشن |
| `anton` | Anton | عناوين قوية عريضة |
| `oswald` | Oswald | الوثائقي الحديث |
| `playfair` | Playfair Display | الدراما الأنيقة |
| `cormorant` | Cormorant Garamond | الطابع الكلاسيكي الراقي |
